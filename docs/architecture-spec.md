# Спецификация архитектуры веб-приложения «Социальная сеть» (Вариант 13)

Архитектурное проектирование выполнено в соответствии с архитектурным шаблоном **MVC + Service Layer (Model-View-Controller с сервисным слоем бизнес-логики)**, развивающим принципы разделения ответственности и инверсии зависимостей (SOLID: DIP).

Проект опирается на эталонную структуру и стандарты проектирования лабораторной работы №5:

## Архитектурные слои системы

* **Presentation Layer (Слой представления / Контроллеры):**
  - Классы: `UserController`, `PostController`, `SubscriptionController`.
  - Роль: прием входящих HTTP-запросов (REST API / Web UI), извлечение входных параметров, вызов соответствующих сервисов приложения и возврат клиенту форматированного ответа (JSON / HTML).
  - Правило: контроллеры остаются «тонкими» — в них полностью отсутствует бизнес-логика и прямые вызовы к базе данных.

* **Application Layer / Service Layer (Сервисный слой):**
  - Классы: `UserService`, `PostService`, `SubscriptionService`, `FeedService`.
  - Роль: оркестрация прикладных сценариев и инкапсуляция всех ключевых бизнес-правил:
    - Проверка запрета подписки на самого себя (`followerId != authorId`);
    - Защита от создания повторных подписок на одного и того же автора;
    - Контроль прав авторства при редактировании и удалении публикаций (`post.authorId == currentUserId`);
    - Формирование и пагинация персональной новостной ленты на основе подписок.

* **Business Layer (Бизнес-модель / Сущности):**
  - Сущности: `User`, `Post`, `Comment`, `Subscription`.
  - Интерфейсы репозиториев: `IUserRepository`, `IPostRepository`, `ICommentRepository`, `ISubscriptionRepository`.
  - Роль: представление данных предметной области, инварианты сущностей и абстрактные контракты доступа к хранилищу.

* **Data Access Layer (DAL / Слой доступа к данным):**
  - Классы: `DatabaseConnection`, `SqlUserRepository`, `SqlPostRepository`, `SqlCommentRepository`, `SqlSubscriptionRepository`.
  - Роль: выполнение подготовленных SQL-запросов к СУБД, управление транзакциями и сборка доменных объектов (гидратация). Все SQL-запросы изолированы исключительно в этом слое.
